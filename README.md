# Trividha Solar Website

Premium static website for Cloudflare Pages.

## Files
- `index.html`
- `about.html`
- `privacy-policy.html`
- `terms-conditions.html`
- `style.css`
- `script.js`
- `404.html`
- `manifest.json`
- `robots.txt`
- `sitemap.xml`
- `_headers`
- `_redirects`
- `assets/*`

## Deployment
Upload the folder to Cloudflare Pages with the project root as the publish directory.
No build command is required.

## Notes
- The design uses Google Fonts, AOS and Lucide from CDN.
- Security headers are included in `_headers`.
- WhatsApp and call numbers are placeholders and can be replaced.
